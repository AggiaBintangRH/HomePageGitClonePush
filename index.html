Security & privacy

Clear boundaries for your account and code.

Git Client is designed to keep GitHub authentication separate from the Git repository metadata you work with locally.

  • Authentication is performed through GitHub.
  • GitHub passwords are not entered into the application.
  • OAuth tokens are application credentials for the authenticated session.
  • Git credentials should not be embedded into repository remote URLs.
  • Authentication credentials are stored using Android platform security mechanisms.

Questions, answered

FAQ.

What is Git Client?

Git Client is an Android application for authenticating with GitHub and working with accessible repositories locally.

Do I need to create a GitHub token manually?

No. The application uses the GitHub authentication flow so you can authorize access through GitHub.

Does Git Client ask for my GitHub password?

No. GitHub authentication happens through GitHub, and Git Client does not provide its own GitHub password form.

Can I use private repositories?

Access depends on the permissions granted to the authenticated GitHub account and the repository's visibility.

Does Git Client store my GitHub password?

No. GitHub passwords are not entered into or stored by Git Client.

Do I need a GitHub account?

Yes. GitHub authentication and repository access require a GitHub account.

Is Git Client affiliated with GitHub?

Git Client is an independent application and is not affiliated with or endorsed by GitHub, Inc.
