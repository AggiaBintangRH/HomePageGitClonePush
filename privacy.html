Privacy Policy

A practical notice about the information Git Client may access when you use the application.

Last updated: 5 October 2026

1. Overview

This notice describes how Git Client handles information involved in GitHub authentication and repository work. It is written as practical product documentation and is not legal advice.

2. GitHub Authentication

Authentication occurs through GitHub OAuth. Git Client does not provide its own GitHub password form. When you authorize the application, GitHub determines the account identity and access granted to the application.

3. Information the Application Accesses

Depending on the permissions granted and the operations you request, Git Client may access your GitHub account identity, repositories you can access, repository metadata, and Git content needed for requested Git operations.

4. Authentication Credentials

Authentication credentials are maintained by the Android application for authenticated operations. The application uses Android platform security mechanisms for protected session storage. Do not share credentials or authorize an application you do not recognize.

5. Repository Data

Repositories you clone may be stored locally on your Android device. Local files and Git history remain on the device until you remove them or the application removes them as part of its normal behavior.

6. Network Communication

GitHub-related functionality communicates with GitHub services when needed for authentication, repository browsing, and remote Git operations such as pull and push.

7. Analytics

We do not currently use third-party advertising or analytics services in this website.

8. Third-Party Services

GitHub is a third-party service used for authentication and repository access. Review GitHub's Privacy Statement for information about GitHub's own practices.

9. Data Retention

This website has no application backend that retains repository data. Local data may remain on your device until removed by you or by the application. GitHub may retain information under its own policies.

10. Security

Reasonable product and platform measures are used to protect application credentials and local data, but no software or transmission method can be guaranteed to be completely secure.

11. Changes to This Policy

This notice may be updated when the application's data practices change. The date above indicates the latest intended revision.

12. Contact

For privacy questions, contact aggiaramadhan@gmail.com.
